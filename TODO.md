# What is left

Ordered by how much each one changes the experience, not by how hard it is.

## Before any store release

- [ ] **Confirm 0.10.0 onwards in game.** The follower fix, the Appearance tab, third-party
      opinions and reactions to what you do all compile and none has been seen working.
- [ ] **Replace the PayPal placeholder** in `README.md` — currently `paypalme/REPLACE_ME`.
- [ ] **Stop hard-coding one machine's profile path** in `Directory.Build.props:12`. Nobody
      else can build without editing it.
- [ ] Package for Thunderstore: `dist/` zip with `manifest.json`, `icon.png`, `README.md`,
      `CHANGELOG.md` and the DLL at the right depth.
- [ ] mod.io page (Shadows of Doubt uses mod.io, **not** Steam Workshop). Images already
      generated by `assets/make_images.py`.
- [ ] Tag a GitHub release with the same zip.

## Consequences that evaporate

The single worst inconsistency in the mod right now. Conversations persist between sessions;
what they achieved does not.

- [ ] **Persist allegiance** — somebody remembers swearing loyalty word for word and is no
      longer your ally. That contradiction is worse than having no memory at all.
- [ ] **Persist outstanding prices** from `Negotiation`.
- [ ] **Persist followers**, or at least say goodbye properly on load.

## Making the city feel alive

- [ ] **Let citizens speak to you first.** Nobody ever opens their mouth unprompted. Someone
      who owes you a favour should greet you; someone who hates you should say so as you pass.
      Everything needed - relationship, memory, earshot - already exists. Probably the single
      biggest gain per hour of work in this list.
- [ ] **React to ordinary life, not only to violence.** Triggers currently cover crimes, fear,
      fights, fleeing and you drawing a weapon. Not rain, not the hour, not walking into the
      same bar for the third time.
- [ ] **Bring up what they remember.** They keep the history and never raise it unprompted.
- [ ] **Let a rumour you started spread.** Gossip currently moves only sightings the game
      recorded, so you cannot seed something and watch it travel - which is half of what the
      mod's name promises.

## World impact still missing

- [ ] **Keys and evidence.** A `WalletItem` is a record, not an object; handing one over means
      spawning a real item and that is unsolved. Cash already works.
- [ ] **Delayed requests** — "meet me at the bar at ten" has nowhere to go.
- [ ] **Fleeing a named person** is an approximation (flee state plus going home), because
      `inFleeState` has no target of its own.

## Prompt and model behaviour

- [ ] **Measure more than the mugging.** `attack_the_investigator` went from 0/3 to 3/3 once
      worked examples were added to the prompt; nothing else has been measured that way. Bribery,
      testimony and turning people against each other deserve the same treatment.
- [ ] **Verify goal preset names.** `GoalDirector` matches by keyword against names that live in
      Unity assets. The Debug tab dumps the real list — run it once in a loaded save and correct
      the mapping.
- [ ] Consider a smaller prompt. It is the main driver of both latency and credits, and history
      is the biggest part of it.

## Tests

- [ ] Extend `tests/` beyond parsing. `Voice.Parse` and the effect conflict resolution are pure
      and untested; both would need a small `ModConfig` shim.
- [ ] A scripted scenario harness, so the mugging measurement can be re-run after prompt changes
      instead of being rebuilt by hand each time.

## Known and accepted

- Player2 TTS takes about 45 seconds for a short line, so it is unusable for live dialogue.
  Babbler is the answer until that changes.
- Player2 STT returns a transcript with no amplitude, so whisper/shout detection from a real
  microphone would mean measuring it locally.
- `CommunityCaseLoader` throws `MissingMethodException` against the current game build. Not
  ours, harmless, and it will keep appearing in the log.
